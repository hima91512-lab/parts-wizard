# Parts Wizard — فاحص قطع الغيار

تطبيق ويب للموبايل (PWA) لفحص قطع غيار المعدات الثقيلة في المستودع:

- **مسح لايف بالكاميرا** لأكواد QR و DataMatrix والباركود (Code128 / Code39 / EAN)، من غير ما تصوّر.
- **التعرّف على رقم القطعة** من الكود (زي باركود CAT `CATAAMX--4798991` وباركود Komatsu) أو من نص الملصق.
- **قاعدة بيانات موثّقة** (`data/parts.json`) فيها البدائل الأصلية (OEM)، والـSupersession، وبدائل الـAftermarket، والمعدات، وكل رقم معاه مصدره.
- **قراءة ذكية بالـAI (اختياري):** بمفتاح Claude API من الإعدادات، لقراءة الملصقات اللي مفيهاش كود، وللبحث عن البدائل والمعدات للقطع اللي مش في القاعدة.
- **سجل فحص** على الموبايل، وتصدير CSV.
- **طلب توثيق:** بيفتح Issue على GitHub عشان القطعة تتراجع وتتضاف للقاعدة.

## التشغيل
افتح لينك GitHub Pages من Safari أو Chrome، وبعدين اختار **Add to Home Screen**.

## التطوير
- الكود في `src/app.jsx` و`src/index.html`.
- البناء بالأمر `node build.js`، وبيطلّع `app.js` و`index.html` في الـroot.
- إضافة قطعة موثّقة: سجل جديد في `data/parts.json`.
